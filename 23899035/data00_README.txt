Integrating databases for spatial analysis of parasite-host associations 
and the novel Brazilian dataset 
Gabriella L. T. Cruz, Gisele R. Winck, Paulo S. D’Andréa, 
Eduardo Krempser, Mariana M. Vidal, Cecilia S. Andreazzi

Funding: MCTI/CNPq Sinbiose.

## This README.text file includes the basic information about the dataset files.

This new dataset represents the best information currently available on 
parasite-host associations in Brazilian regions, including host traits, 
and zoonotic microparasite transmission mode, which may allow the 
scientific community to characterise macroecological patterns as well as 
determine: i) priority areas for parasite surveillance, ii) priority species 
(i.e., mammal or parasite) to be monitored, and iii) integrate environmental 
Brazilian datasets to the BMPO to improve the accuracy of predictive zoonosis 
risk models. Our synthesis also contributes to address some interesting 
Brazilian parasite-host biodiversity questions: (i) which species parasite 
wild free-ranging native mammals, (ii) which species comprise parasite 
hosts, (iii) where are the parasites located, and (iv) which parasites 
are found in a certain region. 

Period of study: Data collection reported on studies ranging from January 1941 
to April 2021.

DATASET FILES USED TO SEARCH

# List of zoonotic microparasites:
List of zoonotic microparasites that was used to search host-parasite 
association at the PubMed platform, GBIF, and the Nucleotide databases.
File type: xlsx

# List of Brazilian wild mammals:
List of native Brazilian mammal species that was used to search 
host-parasite association at the PubMed platform.
File type: xlsx

# List of primary papers:
List of primary papers used to retrieve first and last authors' names. 
Subsequently, this list was used to search in the Brazilian curriculum 
vitae platform papers reporting host-parasite association.
File type: xlsx


END PRODUCT DATASET FILES

# NCBI Nucleotide data:
Data of zoonotic microparasites gathered from NCBI Nucleotide database.
File type: RData
These *.RData file is read into R with a ‘load’ statement.

# GBIF data:
Data of zoonotic microparasites gathered from GBIF database.
File type: RData
These *.RData file is read into R with a ‘load’ statement.

# Brazilian Mammal Parasite Occurrence Data (BMPO):
Data of parasite-host gathered from multiple references, integrating 
wild mammal species’ morphological and life-history traits, 
zoonotic parasite status, and zoonotic microparasite transmission modes.
File type: xlsx

# Metadata description of the BMPO:
Variables description of the BMPO and from the associated lists.
File type: xlsx
